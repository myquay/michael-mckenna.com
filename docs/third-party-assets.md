## Recorded provenance

### W95FA

Runtime: [`w95f.woff2`](../blog/static/fonts/w95fa/w95f.woff2).
See the bundled [OFL](../blog/static/fonts/w95fa/OFL.txt),
[original readme](../blog/static/fonts/w95fa/readme.txt), and
[provenance notice](../blog/static/fonts/w95fa/NOTICE.md) for the download source,
version, retrieval date, and SHA-256. The supplied OFL has placeholder copyright
lines, preserved verbatim; the author distribution and embedded font metadata
identify the OFL. This is the only font binary bundled with the site.

MS Sans Serif, Microsoft Sans Serif, Arial, Georgia, Times New Roman, Courier,
and the generic CSS families are local/system fallbacks, not downloaded font
assets. The Windows branding rail also uses local Arial.

### Windows artwork

The 23 numbered icons were present before this inventory. The initial theme
commit (`ba19fc2`) and subsequent icon commits do not identify their download
source. An expanded local catalogue exists in ignored `design/win95-icons/`;
it is not published. The selected 24 runtime ICOs are listed individually below.

The Internet icon's provenance was recovered from `HEAD:docs/the-internet-icon.md`
(the working-tree file had been deleted; this inventory does not restore it).
That record identifies [this source image](https://www.spriters-resource.com/media/assets/203/205888.png?updated=1755489387),
a crop from (193, 14) to (225, 46), and conversion of the cyan background to
transparency. The record attributes the original artwork to Microsoft. Live
retrieval of the archive page was unsuccessful during this inventory; the source
is supported by the repository history, not a newly verified license grant.

### Locally generated graphics

The two RSS graphics have corresponding generators in ignored
`design/rss-icons-95/generate_icons.py` and `generate_wizard_panel.py`.
The three first-webpage graphics are generated by
[`generate-first-webpage-assets.py`](../scripts/generate-first-webpage-assets.py).
These are locally drawn outputs, not recorded downloads. Their familiar visual
motifs do not by themselves establish the source of any underlying design.
The construction lettering uses Pillow's default font; the exact Pillow/font
version used to create the existing binaries was not recorded.

Window-control glyphs, scrollbar arrows, bevels, stippling, and the clock are
implemented directly in theme CSS/SVG/templates. No external icon library is
used for the new Phase 1 controls.

## Follow-up and maintenance

- Record the original numbered-icon source and any accompanying license or permission information.
- Confirm the origin of the other media, particularly the favicon, newspaper graphic,
  personal icons/buttons, and any images copied from another site. Screenshots of
  third-party products are not automatically stock images, but may contain third-party artwork.
- Record the Pillow/default-font version when regenerating the construction graphics.
- For each new imported asset, record creator, exact source URL, license, local path,
  modifications, and retrieval date. Keep required attribution/license files beside it.
- Update this document when adding/removing assets. Retain the distinction between
  imported files, locally generated outputs, and media with unconfirmed provenance.
