# The Internet icon

The 32 × 32 globe-and-magnifying-glass icon is extracted from the Windows 95 Internet Explorer sprite sheet archived at:

https://www.spriters-resource.com/ms_dos/windows95/asset/205888/

Source image: https://www.spriters-resource.com/media/assets/203/205888.png?updated=1755489387

The icon occupies (193, 14) through (225, 46), with the cyan sheet background made transparent. Runtime file: `blog/static/images/win95-icons/the-internet.ico`. Original artwork belongs to Microsoft.
